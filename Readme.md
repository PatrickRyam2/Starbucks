# ☕ Starbucks Clone

Projeto desenvolvido durante meus estudos de Desenvolvimento Front-End, inspirado na interface do Starbucks.

## 📌 Sobre o projeto

O objetivo deste projeto foi praticar a criação de uma interface web utilizando HTML e CSS, trabalhando com estruturação de conteúdo, estilização e organização dos elementos da página.

Este projeto faz parte do meu processo de aprendizado em desenvolvimento web e da construção do meu portfólio.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## ✨ Conceitos praticados

- Estruturação de páginas com HTML
- Estilização com CSS
- Organização de layouts
- Flexbox
- Posicionamento de elementos
- Utilização de imagens
- Construção de interfaces inspiradas em aplicações reais

## 🎯 Objetivo

Praticar fundamentos de Desenvolvimento Front-End e desenvolver minha experiência na criação de interfaces utilizando HTML e CSS.

## 🚧 Status

Projeto desenvolvido para fins de estudo.
